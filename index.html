🚀 نسخه واقعی برنامه

برای اجرای نسخه کامل با هوش مصنوعی واقعی:

دستورات اجرا:

# 1. دریافت کد پروژه
git clone https://github.com/niloufarmtd/smart-student-time-manager.git

# 2. رفتن به پوشه پروژه
cd smart-student-time-manager

# 3. نصب نیازمندی‌ها
pip install streamlit pandas plotly

# 4. اجرای برنامه
streamlit run app.py

سپس مرورگر خود را باز کنید و به آدرس زیر بروید: http://localhost:8504
